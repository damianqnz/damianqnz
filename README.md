## 🚀 What I'm building

### SkinSystem — Multi-tenant SaaS for Health & Beauty Professionals
> A platform for aesthetic clinics and beauty salons to manage appointments, clients, inventory, and payments from a single dashboard.

**Highlights:**
- Multi-tenant architecture with PostgreSQL Row Level Security (complete data isolation per account)
- Stripe Connect (Standard) — each specialist processes payments through their own connected account
- Automated WhatsApp communications via Evolution API + transactional emails via Resend
- Internationalization for 3 languages (ES/EN/PT) with next-intl
- Biometric re-authentication via WebAuthn API

**Stack:** Next.js 16 · TypeScript · PostgreSQL / Supabase · Drizzle ORM · Stripe Connect · Upstash Redis · Tailwind CSS · Shadcn/ui · Zod · Playwright

---

### Direct Booking Platform — Property Reservation System
> A direct booking system for a Lisbon accommodation, replacing dependency on third-party platforms and eliminating intermediary commissions.

**Highlights:**
- Dual authentication (Google OAuth + credentials) with NextAuth v5
- Secure payment processing via Stripe webhooks
- Responsive transactional email templates with React Email + Resend
- Image management through Cloudinary

**Stack:** Next.js 16 · TypeScript · PostgreSQL / Prisma 6 · Stripe · NextAuth v5 · React Hook Form · Zod · Tailwind CSS
